# Student Study Planner – Requirements

## 1. Functional Requirements

* The system shall provide Login and Registration pages.
* The system shall allow users to navigate between pages.
* The system shall display a Home Dashboard.
* The system shall allow students to add study tasks.
* The system shall display the study schedule.
* The system shall track and display study progress.

## 2. Non-Functional Requirements

* The website should have a simple and user-friendly interface.
* The website should use a consistent colour theme and layout.
* The pages should be responsive on desktop and mobile devices.
* The forms should validate user inputs.
* The website should work in modern web browsers.

## 3. Software Requirements

* Operating System: Windows
* Code Editor: Visual Studio Code
* Frontend: HTML, CSS, JavaScript
* Browser: Google Chrome
* Version Control: Git and GitHub
* Development Server: Live Server extension

## 4. Hardware Requirements

* Computer or laptop
* Keyboard and mouse
* Minimum 4 GB RAM recommended

## 5. Project Constraints

* The current project is a frontend web application.
* Browser Local Storage may be used for demo data.
* Secure, real-user authentication requires a backend and secure password handling.
