# 📚 Student Study Planner

## About the Project

Student Study Planner is a web application designed to help students organize their study schedules, manage daily tasks, and track their learning progress.

## Objectives

* Organize daily study activities.
* Manage study tasks and schedules.
* Monitor study progress.
* Provide a simple and user-friendly interface.

## Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage (for the current demo)

## Main Features

* Login and Registration pages
* Home Dashboard
* Study Schedule
* Add Study Task
* Progress Tracker

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.

## Project Status

Academic project — development and testing in progress.
